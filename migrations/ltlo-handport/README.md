# LTLOHandportMigration

One-shot helper for switching from dej's MWSE hand port of Leave The Lights Off to the
omwcompat build of the original mod. It removes the hand port's unlit copies and re-enables
the originals it hid, cell by cell, then deletes `tes3.player.data.leavethelightsoff`.
Safe to leave installed (it does nothing once that data is gone); remove it after one play
session in each save you care about. MIT, Copyright (c) 2026 dej (dejunai).
