## New game?

- **The MCM and tunables do not need a new game.** Values are in
  `DF\MWSE\config\omwcompat_LeaveTheLightsOff.json`, not in the save. The defaults are the
  author's values.
- **Moving from the hand port to the omwcompat build does, for any save where the hand port
  ran.** Without the migration helper, the hand port's placed off copies and disabled
  originals stay in those saves, and the omwcompat build does not know about them. Use a new
  game, or a save from before the hand port was installed. (Saves without any LTLO are fine.)
